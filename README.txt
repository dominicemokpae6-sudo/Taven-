TAVEN — RESPONSIVE STREETWEAR STOREFRONT

Files
- index.html: the complete storefront page
- css/style.css: responsive layout, typography, product cards and animations
- js/app.js: product filters, search, cart drawer, quantity controls and WhatsApp checkout
- images/: cropped product imagery from the screenshots supplied for this project

How to preview
1. Extract the ZIP file.
2. Open index.html in a modern browser. The site works as a static website; a local web server is recommended for best results.

How to publish free
- GitHub Pages: upload the contents of this folder to a repository and enable Pages in repository Settings.
- Netlify: drag the extracted taven_site folder into Netlify Drop, or connect the repository.

Important setup notes
- Product names and prices are based on the screenshots provided. Confirm stock, sizes and prices with Taven before publishing.
- WhatsApp order links currently use the number visible in the supplied profile screenshot: +234 708 501 4475.
- Telegram and TikTok links use the handles visible in the screenshot.
- The cart is front-end only and sends the order summary to WhatsApp; it does not take card payments or store orders in a database.
- Google Fonts requires an internet connection; fallback fonts are included.
